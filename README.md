# Welcome

I have been doing systems programming (servers, compilers, databases) and working on DPI and network intrusion detection for almost 30 years.
I am writing about my programming experiences on a [blog](https://www.scaramanga.co.uk).

## Active Open Source Projects
- ⚡ I'm currently working, in my spare time, on [resynth](https://github.com/giannitedesco/resynth) which is a small language for generating pcaps of network traces. It's useful for testing and validating packet-processing pipelines.
- 👷 I maintain [minotaur](https://github.com/giannitedesco/minotaur) - a sync/async inotify interface for python
- 🌱 I’m currently learning Rust and C++
- 🕹️ I am interested in SNES emulation, and the SPC700 audo processing unit in particular. I wrote a little emulator for that called [spu-kit](https://github.com/giannitedesco/spu-kit) - i am getting interested in the idea of 6502 code-translation (ala qemu) and have been noodling around with that.

## Sporadically Developed Projects
I plan to get around to tidying up and releasing more of these soon.
- [hieros](https://github.com/giannitedesco/hieros) - An x86-64 kernel.
- zipfuel - A graphical order-flow analysis system for high-frequency trading, also contains an order-book reconstruction/simulation system
- saggy - A rust software-defined radio stack, it's a basic rust DSP library which can talk to RTL-SDR devices, and do downsampling, filtering, decoding. It has an FM radio decoder and I started looking at implementing POCSAG (analog pager system) with it.
- brrapp - A graphical BRR sample ripper/viewer using rust egui
- radon - An SQL query compiler and database system
- shaft - A fast SSE-accelerated web-server utilizing io_uring and a statically-compiled content database
